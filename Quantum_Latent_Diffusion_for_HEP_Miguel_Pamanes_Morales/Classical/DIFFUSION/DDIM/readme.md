In this section, we present the Denoising Diffusion Implicit Model (DDIM). Building upon the same base architecture and training objective as the DDPM, we introduce the modifications specific to a DDIM—namely, replacing the Markovian reverse process with a non-Markovian, deterministic one to enable accelerated sampling. As an initial experiment, the model was trained on a reduced dataset of 10,000 jet images.
